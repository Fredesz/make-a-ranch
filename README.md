# Make a Ranch

Make a Ranch es un juego de Roblox desarrollado utilizando Luau, Rojo y GitHub.

## Herramientas

- Roblox Studio
- Luau
- Rojo
- Rokit
- Git
- GitHub

## Estructura

src/
- client/ → código ejecutado por el cliente
- server/ → código ejecutado por el servidor
- shared/ → módulos compartidos entre cliente y servidor

## Desarrollo

Instalar las herramientas del proyecto:

rokit install

Iniciar Rojo:

rojo serve

Después, abrir Roblox Studio y conectar el plugin de Rojo a:

localhost:34872

## Git

- `main` → versión estable
- `develop` → desarrollo
- `feature/*` → nuevas funcionalidades
